============================================================
Multi-word keywords
============================================================

```catala
deklaracja struktura P:
  dane n typu całkowita

deklaracja enumeracja E:
  -- A typu całkowita
  -- B

deklaracja zakres S:
  wejście l typu lista całkowita
  wejście c typu zerojedynkowy
  wejście p typu P
  wejście v typu E
  wyjście f typu całkowita zależy od x typu całkowita
  wyjście m typu lista całkowita
  wyjście q typu lista całkowita
  wyjście t typu lista całkowita
  wyjście e typu zerojedynkowy
  wyjście k typu całkowita
  wyjście s typu całkowita
  wyjście r typu P
  wyjście g typu lista całkowita

zakres S:
  definicja f z x pod warunkiem c konsekwencja wynosi x
  definicja m wynosi plan każdy x wśród l do x + 1
  definicja q wynosi
    sort wszystkie x wśród l by decreasing order z x and then - x
  definicja t wynosi sort l by increasing order
  definicja e wynosi v ze wzorem A
  definicja k wynosi maksimum z l lub jeżeli lista pusta wtedy 0
  definicja s wynosi
    połączyć wszystkie x wśród l w acc początkowo 0 wraz z acc + x
  definicja r wynosi p ale zastąpić { -- n: 1 }
  definicja g wynosi lista x wśród l takie że to x > 0
```
